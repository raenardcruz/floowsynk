# Stripe API Integration Guide for n8n
## 1. Overview
Provider: Stripe
API Type: REST API
Primary Auth Method: API Secret Key (sk_live_... / sk_test_...) or Restricted Key (rk_...)
Official Docs: [Stripe API Reference](https://stripe.com/docs/api)
## 2. Required Authentication Parameters
Secret Key: Secret key string starting with sk_test_ or sk_live_.
Restricted Key (Alternative): Custom key starting with rk_test_ or rk_live_.
Webhook Signing Secret: Starts with whsec_ (required for Stripe Trigger node).
## 3. Step-by-Step Instructions to Obtain Data
Retrieve Secret Key:
Log in to [Stripe Dashboard](https://dashboard.stripe.com/).
Toggle between Test mode and Live mode as needed.
Go to Developers > API keys.
Under Standard keys, locate Secret key and click Reveal secret key (or click Create restricted key for scoped permissions).
Copy the secret key string.
Retrieve Webhook Signing Secret (for Stripe Triggers):
Go to Developers > Webhooks.
Click Add an endpoint.
Paste the Webhook URL generated by n8n Stripe Trigger: https://<n8n-host>/webhook/stripe.
Select events to monitor (e.g., checkout.session.completed, customer.subscription.created).
Click Add endpoint.
Under Signing secret, click Reveal and copy the string starting with whsec_.
## 4. Base Endpoints & Key Resources
Base URL: https://api.stripe.com/v1
Customers:
GET /v1/customers
POST /v1/customers
Payment Intents:
POST /v1/payment_intents
Subscriptions:
GET /v1/subscriptions
## 5. Header / Request Format
Authorization: Bearer sk_test_YOUR_SECRET_KEY

Content-Type: application/x-www-form-urlencoded

Note: Stripe API expects form-urlencoded body data for POST/PUT requests.
## 6. n8n Implementation Notes
Credential Setup: In n8n, select Stripe API and enter your Secret Key.
Webhooks: For event-driven automation, use the Stripe Trigger node and enter both Secret Key and Webhook Signing Secret.
